## 어디까지 왔나

코드는 게임 8개, **서버(허브)에 보이는 건 셋뿐**(똥 피하기·쥬라기 대탐험(3D)·
인터랙션 웜업) — 나머지 다섯은 `status: hidden`으로 보관, 코드는 안 지웠다.
자세한 이유는 `CLAUDE.md`의 "지금 위치" 표. 테스트 710건 · **크롬에서만 확인됨.**

쥬라기 대탐험(3D, 옛 이름 "쥬라기 런 3D")은 타이틀 → 카메라 준비 → 튜토리얼 →
판 → 결승 포털 → 엔딩 → 결과까지 한 바퀴가 다 돈다.

`#/labcam` 실측 완료(STEP 20) — 세로가 화각을 넓혀줄 거라는 예상은 **틀렸다**
(맥북캠은 오히려 좁아짐). 대신 **관절 요구를 줄이는 쪽은 확인됐다** — 경계
거리에서 발목 요구를 빼면 8개 중 6개가 통과로 바뀐다. 다음 할 일이 이 결과를 반영하는 것.

`main`은 커밋까지 돼 있고 **푸시는 ken이 직접 한다**(맥 키체인에 인증이 있다).

## 자주 밟는 것

- **서버는 ken이 켠다** — `npm run dev`. Claude의 셸은 별도 리눅스라 맥의 5173에 못 닿는다
- **확인은 `npm run check`** — 테스트·빌드·맥용 rollup 바이너리·에셋 용량을 한 번에
- 리눅스에서 `npm`을 돌리면 맥용 rollup 바이너리가 빠질 수 있다. `check`가 잡는다
- 템플릿 문자열(CSS·HTML) 안 주석에 **백틱을 쓰지 않는다** — `test/sourceParses.test.js`가 잡는다
- `tools/ai_inbox/`는 깃에 안 올라간다(파일 하나가 60MB). 정본은 `tools/blender/*.py`다
