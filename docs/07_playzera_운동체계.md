# 플레이 제라 — 운동 체계

> 2026-08-09 · "우리가 세는 것이 정말 운동인가"를 정리한 문서
> 기획은 `docs/01`, 성장은 `docs/05`. 여기는 **몸이 무엇을 하는가**만 다룬다.

---

## 1. 왜 이 문서가 필요했나

`CLAUDE.md` 첫 줄은 "운동 데이터가 쌓이는 것이 이 서비스의 존재 이유"다.
그런데 정작 **무엇을 운동으로 세는지**가 정해진 적이 없었다. 게임을 만들면서
그때그때 지표가 생겼고, 그래서 지금 세는 넷이 한쪽으로 쏠려 있다.

| 지금 세는 것 | 분류 |
|---|---|
| `jumps` 점프 | 이동 · 순발력 |
| `squats` 앉기 | 안정 · 근력 |
| `side_steps` 좌우 | 이동 · 민첩 |
| `pose_holds` 포즈 | 안정 · 유연 |

넷 다 **"제자리에서 몸통·다리"**다. 빠진 축이 셋이다.

- **유산소** — 숨이 차는 구간이 하나도 없다. 전부 짧은 반응이다
- **균형** — 한 발로 버티는 동작이 없다
- **팔·정중선 협응** — 팔을 쓰는 동작이 없다

---

## 2. 뼈대 — 기본운동기술(FMS)

유아체육의 기본운동기술은 셋으로 나뉜다.

| 갈래 | 뜻 | 예 |
|---|---|---|
| **이동** | 몸이 자리를 옮긴다 | 걷기·달리기·뛰기·갤로핑 |
| **안정** | 제자리에서 축을 중심으로 움직인다 | 균형·굽히기·비틀기·뻗기 |
| **조작** | 물체에 힘을 주고받는다 | 던지기·받기·차기 |

셋 중 **안정 기술이 가장 자주 빠지는데, 실제로는 나머지 둘의 토대**다.
우리도 정확히 그 상태였다.

**운동량 기준** — WHO는 3~4세에게 하루 180분 신체활동(그중 60분은 중강도 이상),
5세 이상에게 하루 60분 중강도를 권한다. 우리 하루 목표 30분(`report.js`의
`DAILY_GOAL_MIN`)은 **그 일부를 이 앱이 맡는다**는 뜻이다. 나머지는 바깥에서 뛰어야 한다.

### 4~8세에 특히 값이 큰 것

- **한 발 균형** — 모든 동작의 토대, 넘어짐 예방
- **정중선 교차**(오른손으로 왼쪽 무릎 치기) — 좌우 협응 발달
- **리듬 맞추기** — 박자에 몸을 맞추는 것 자체가 협응 훈련
- **자기 체중만 쓰는 근력** — 기구는 쓰지 않는다

## 3. 진짜 제약은 "카메라가 읽는가" ★

여기가 이 프로젝트의 핵심 제약이다. 유아체육 교재에 좋은 동작이 아무리 많아도
**정면 2D 웹캠이 못 세면 우리에게는 없는 동작**이다.

이미 겪었다 — 정면 런지는 깊이가 안 읽혀서 포즈 점수가 0.36까지 떨어졌다(`docs/04` STEP 4).

### 바로 되는 것

| 동작 | 판정 방법 | 메우는 축 |
|---|---|---|
| **제자리 달리기** | 무릎 y가 교대로 올라감 | 유산소 |
| **한 발 서기** | 두 발목의 y 차 + 유지 시간 | 균형 |
| **점핑잭(별 만들기)** | 손목 x 벌어짐 + 발목 x 벌어짐 | 유산소·협응 |
| **크로스 터치** | 손목이 반대편 무릎에 근접 | 정중선 협응 |
| **옆으로 굽히기** | `torsoTilt` — 코드가 이미 있다 | 유연 |
| **발차기** | 발목 y 상승 + 무릎 신전 | 조작 대역·균형 |

### 조건부 (되지만 손이 더 간다)

- **몸통 비틀기** — 정면에서 어깨 너비가 줄어드는 **비율**로 판정. 각도가 아니라 비율이라 튜닝이 필요
- **던지기 흉내** — 팔꿈치·어깨 각속도. 공이 없으니 동작 흉내까지만
- **앞뒤 이동** — 어깨 너비 픽셀로 거리 추정. 오차가 커서 3구역 정도만

### 하지 말 것

구르기 · 기어가기 · 바닥에 앉는 스트레칭(프레임 밖·가림),
빠른 제자리 회전(좌우 랜드마크가 뒤집힌다), 실물을 던지고 받기.

## 4. 세는 방식 — 횟수만 세면 안 된다 ★

`jumps`는 원래 "뛰었나"만 봤다. **대충 흔들어도 오른다.**
그런 값은 운동 데이터가 아니라 움직임 데이터다.

그래서 모든 동작에 **품질 문턱**을 적어 두고 감지기가 그걸 지킨다.
문턱은 `src/progress/exercises.js`의 `quality` 필드에 **말로** 적혀 있다 —
숫자는 감지기에, 약속은 사전에.

| 동작 | 문턱 |
|---|---|
| 점프 | 골반이 키의 4% 이상 상승 + 상승 속도 |
| 앉기 | 골반이 충분히 내려갔다 다시 서기 |
| 좌우 | **실제로 자리를 옮겨야** — 피한 개수(dodge)는 쓰지 않는다 |
| 포즈 | 목표 자세 2~3초 유지 |
| 달리기 | 무릎이 서 있을 때보다 **키의 10% 이상** |
| 균형 | 한 발이 확실히 뜬 동안만 초를 센다 |

**문턱은 전부 `bodyHeight` 비율이다.** 아이 키·카메라 거리와 무관해야 한다(프로젝트 공통 규칙).

## 5. 이번에 구현한 것 (8/9)

### 운동 사전 — `src/progress/exercises.js`

동작을 **데이터로** 둔다. 게임·버디·배지를 registry 한 줄로 늘리는 것과 같은 규칙이다.

```
key      기록에 쌓이는 이름 (state.totals[key])
exp      1회(또는 1초)당 EXP — 활동 1초 = 1이 기준
unit     화면에 붙는 단위
quality  감지기가 지켜야 할 문턱
safety   4~8세 안전 메모
```

**왜 만들었나** — 지표 이름이 `level.js`·`report.js`·`badges.js`에 흩어져 있었다.
동작 하나를 추가하려면 세 파일을 고쳐야 했고, 한 군데를 빠뜨리면
**EXP는 오르는데 화면에는 안 나오는** 상태가 된다. 지금은 EXP 가중치도,
마이페이지 칸도 전부 여기서 나온다. 테스트로 묶었다.

### 감지기 둘 — `src/core/pose/detectors/`

| 파일 | 세는 것 | 핵심 판단 |
|---|---|---|
| `highKnees.js` | `high_knees`(걸음) · `active_sec` | **캘리브레이션을 안 한다** |
| `balance.js` | `balance_sec`(초) | **횟수가 아니라 시간** |

**달리기 — 캘리브레이션을 안 하는 이유**
웜업의 `MotionDetector`는 3초 서 있게 하고 기준선을 잡는다. 여기서는 안 그런다.
다리는 대부분의 시간을 아래에 두고 있으니, **최근 2초 동안 무릎이 가장 낮았던 위치**가
곧 "서 있을 때"다. 준비 화면을 안 거치는 게임에도 그냥 붙고, 아이가 카메라에서
멀어져도 따라간다.

**균형 — 횟수가 아니라 초인 이유**
"몇 번 섰나"는 발을 들었다 놨다만 반복해도 오른다. **얼마나 버텼나**가 곧 능력이다.
아이는 버티다 발이 잠깐 닿는다 — 0.4초까지는 이어진 것으로 봐준다.
대신 **닿아 있던 시간은 초에 더하지 않는다.** 안 버틴 시간을 세면 그건 거짓말이다.

### 검증하는 방법 두 가지

| 방법 | 무엇을 답하나 |
|---|---|
| `test/detectors.test.js` | **세는 규칙이 맞나** — 가짜 랜드마크를 프레임 단위로 먹인다 |
| `/lab` (DEV 전용) | **웹캠으로 실제로 세나** — 숫자가 실시간으로 오르는 걸 눈으로 본다 |

둘 다 필요하다. 합성 프레임은 사람의 흔들림·조명·거리를 모르고,
카메라만 보면 왜 틀렸는지를 모른다.

### 겪은 것

**1. 무릎을 든 채로 시작하면 첫 걸음을 놓쳤다.**
기준선이 "최근에 가장 낮았던 무릎"인데, 시작부터 들고 있으면 든 위치가 기준이 된다.
→ 창에서 찾은 값이 골반보다 키의 12%도 안 내려가 있으면 서 있는 자세가 아니라고 보고,
몸 비율(골반에서 키의 20% 아래)로 어림한다. **정상일 때는 관찰값을 그대로 쓴다** —
어림값이 상시 끼어들면 과다 카운트가 난다.

**2. 앉아 있는 사람에게서 1걸음이 세어졌다.** `/lab`에서 바로 잡혔다.
MediaPipe는 **화면 밖 관절의 좌표를 지어낸다.** 좌표만 보면 그럴듯하다.
→ `visibility < 0.5`인 프레임은 통째로 버린다. 두 감지기 모두.

## 5-1. 요가 자세 (8/9)

**정리 막을 채우는 것.** 불 끄기로 숨이 찬 뒤 숨을 고르는 자리이자,
유연·안정 축을 함께 메운다.

### 서서 하는 자세만 넣는다

| 넣은 것 | 판정의 핵심 |
|---|---|
| ⛰️ 산 | 두 손 모으기 + **두 발이 바닥에** |
| 🌳 나무 | 한 발 들기 + 무릎 접기 + 손 모으기 |
| ⭐ 별 | 팔·다리 벌리기 |
| ⚔️ 용사 | 팔 수평 + **다리 넓게** + 앞 무릎 굽힘 |
| 📐 세모 | 몸통 기울기 + 다리 넓게 |
| 🦩 홍학 | 한 발 들기 + 팔 수평 |
| 🌵 선인장 | 팔꿈치 ㄱ자 |

뺀 것 — 다운독·고양이소·아기·나비(바닥에 짚거나 앉는다), 의자·런지(앞뒤 깊이),
비틀기(몸이 카메라를 등지면 좌우가 뒤집힌다). 정면 2D의 한계는 요가에서도 같다.

이름은 **동물·사물로** 부른다. "브륵샤아사나"가 아니라 "나무" — 4~8세는 이름으로 기억한다.

### 각도만으로는 안 갈렸다 ★

웜업의 세 자세는 관절 각도만으로 구별됐다. 요가는 아니다.

```
세모 vs 초승달   몸통 기울기·팔 각도가 거의 같다. **다리 벌린 폭**만 다르다
나무 vs 산       팔 각도가 같다. **한 발이 떠 있나**만 다르다
용사 vs 홍학     팔이 수평이고 무릎 하나가 굽는 것도 같다
```

그래서 `poseFeatures`에 **비율**을 넣었다 — `stance`(다리 폭 ÷ 어깨너비),
`armSpan`, `footLift`(발 높이차 ÷ 키), `handGap`(두 손 사이 ÷ 어깨너비).
각도든 비율이든 채점 방식은 같다(`[목표, 허용오차, 가중치, 방향]`).

### 카메라 없이 검증한다 ★

자세마다 **제대로 한 아이의 뼈대**를 좌표로 적고, 모든 자세를 서로 채점한 **표**를 만든다.
`test/yogaPoses.test.js`가 그 표를 매번 검사한다.

```
        산    나무   별    용사  세모  홍학  선인장
산     1.00  0.58  0.43  0.38  0.39  0.38  0.36
나무   0.65  0.96  0.34  0.25  0.28  0.66  0.27
별     0.62  0.25  1.00  0.60  0.58  0.22  0.30
용사   0.42  0.11  0.60  0.99  0.38  0.54  0.46
세모   0.53  0.21  0.66  0.53  1.00  0.22  0.18
홍학   0.28  0.43  0.44  0.65  0.19  0.99  0.58
선인장 0.61  0.22  0.31  0.52  0.24  0.49  0.99
                                     (문턱 0.68)
```

대각선은 전부 0.96 이상, 나머지는 0.66 이하다. **이 표가 목표값을 두 번 고치게 했다.**

- 나무 자세가 **산으로 0.74점**을 받았다. 팔을 올린 자세는 죄다 산과 닮는다 →
  산을 산이게 하는 "두 발이 바닥에"의 가중치를 4까지 올렸다
- 홍학이 **용사로 0.78점**을 받았다. 다리 폭만으로는 안 갈렸다 →
  용사에 "두 발이 다 바닥에"를 새로 넣었다

"가만히 서 있는 것으로는 어떤 자세도 통과하지 못한다"도 테스트로 못 박았다.
서 있기만 해도 통과하는 자세가 있으면 아이는 아무것도 안 하고 보상을 받는다.

> 실기기 확인은 `#/lab`의 **요가 자세** 탭에서 한다 — 자세별 점수와
> "지금 무엇이 깎아먹는지"가 실시간으로 뜬다. 합성 뼈대는 사람의 흔들림·옷·조명을 모른다.

## 6. 앞으로 — 게임에 녹이는 순서

동작을 게임에 흩뿌리지 않는다. **한 판을 3막으로** 짜는 게 유아체육 수업 구조와 맞는다.

```
준비 (1분)   팔 돌리기 · 옆으로 굽히기 · 제자리 걷기
주 운동 (3~5분)  게임 본체 — 점프·스쿼트·좌우·달리기
정리 (1분)   숨 고르기 · 한 발 서기 · 스트레칭
```

게임 후보:

| 게임 | 쓰는 동작 | 노리는 것 |
|---|---|---|
| **불 끄기 소방관** ✅ | 제자리 달리기 | 심박을 올려 **유지**시키는 구간 전용 |
| **돌다리 건너기** ✅ | 한 발 서기 | 균형 하나만 파는 게임 |
| **동물 요가** 🔶 | 요가 7자세 (사전·검증 완료, 게임 미구현) | 정리 막 — 숨 고르기 + 유연 |
| **거울 요정** | 크로스 터치 · 별 만들기 · 비틀기 | 정중선 교차를 자연스럽게 넣는 유일한 방법 |

---

## 7. 안전 (4~8세)

- 연속 점프는 10회쯤에서 끊고 쉰다 — 착지 반복은 무릎에 부담
- 정적 스트레칭을 오래 유지시키지 않는다. 동적 위주
- 포즈 유지는 **2~3초까지**
- 한 발 서기는 넘어질 것에 대비해 주변을 비우고, 한쪽만 오래 하지 않는다
- 달리기는 30초 하고 숨 고르기

안전 메모도 운동 사전의 `safety` 필드에 함께 있다. 게임이 참조할 수 있다.
