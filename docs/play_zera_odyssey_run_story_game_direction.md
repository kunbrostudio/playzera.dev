# PLAY ZERA — ODYSSEY RUN

## 전체 목표

트로이 전쟁을 마친 오디세우스가 고향 **이타카**로 돌아가려 하지만 바다에서 길을 잃는다.

플레이어는 오디세우스가 여러 위험을 통과해 가족에게 돌아갈 수 있도록 돕는 **작은 모험가**가 된다.

전체 구조는:

**START STORY  
→ STAGE 1 : Cyclops Island / LV.1~2  
→ STAGE 2 : Sea of Sirens / LV.3~4  
→ STAGE 3 : Final Voyage / LV.5~6  
→ ENDING**

# 게임 방향성 요약

이번 오디세이 런은 쥬라기 런의 단순 테마 변경이 아니라, **스토리와 운동 방식이 함께 변화하는 확장형 콘텐츠**로 설계한다.

핵심 흐름은 다음과 같다.

**육지 → 바다 → 폭풍 → 괴물 해협 → 이타카 상륙 → 귀환**

운동 구조도 함께 변한다.

**Run → Run on Boat → Row → Mixed → Run → Pose/Aim**

이 구조를 통해 아이가 단순히 레벨을 클리어하는 것이 아니라, **오디세우스의 귀환 여정을 직접 도와 완주했다는 감정적 경험**을 느끼게 하는 것이 목표다.

## 구현 시 주의점

특히 LEVEL 5의 스킬라와 카리브디스는 각각의 역할을 명확히 나누는 것이 중요하다.

- **카리브디스 = 환경형 위험 요소**
- **스킬라 = 캐릭터형 장애물**

이렇게 분리하면 어린 사용자도 규칙을 빠르게 이해할 수 있고, 화면이 복잡해지는 것도 줄일 수 있다.
