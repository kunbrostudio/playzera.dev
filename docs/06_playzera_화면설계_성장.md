# 플레이 제라 — 성장 화면 설계

> 초안 2026-08-05 · 마이페이지 목업 검토 후
> `docs/05` 캐릭터 성장 기획을 화면으로 옮긴 문서다.
> 허브·게임 화면은 `docs/03`에 있다. 여기는 **새로 생기는 화면**만 다룬다.

---

## 1. 화면을 둘로 나눈다 — 아이 것과 부모 것 ★

목업을 보고 확실해진 것: **마이페이지는 훌륭한 부모 화면이다. 그런데 아이 화면은 아니다.**

| | 아이 화면 | 부모 화면 |
|---|---|---|
| 누가 본다 | 4~8세 | 부모·선생님 |
| 조작 | **손 제스처 + 큰 버튼** | 터치 |
| 글자 | 거의 없다 (못 읽는다) | 있어도 된다 |
| 숫자 | 별 개수·게이지 | 분·횟수·그래프 |
| 목표 | "내일 또 하고 싶다" | "얘가 뭘 했나" |

목업 상단의 아이콘 7개(게임 시작·꾸미기·기록·도움말·이벤트·알림·설정)는
**손 커서로 못 누른다.** 작고 촘촘하다. 허브 하단 4칸 바가 손에 안 닿아서 걷어낸 것과 같은 문제다.

**그래서 이 목업은 부모 화면(`/me`)으로 두고, 아이에게는 따로 준다.**

```
아이가 쓰는 것   /            허브 홈 (게임 고르기 + 내 친구 한쪽에)
                /buddy       내 친구 — 크게, 글자 최소, 손으로 조작
                게임 결과     새 배지 축하

부모가 쓰는 것   /me          마이페이지 (목업) — 오늘의 활동·주간 리포트·배지 전체
```

## 2. 화면 목록

| 라우트 | 이름 | 누구 | 언제 |
|---|---|---|---|
| `/start` | 첫 실행 — 프로필·알 고르기 | 아이(+부모) | 최초 1회 |
| `/` | 허브 홈 | 아이 | 늘 |
| `/buddy` | 내 친구 | 아이 | 허브에서 버디를 누를 때 |
| `/me` | 마이페이지 | 부모 | 허브 우상단에서 |
| (오버레이) | 게임 결과 — 배지·레벨 | 아이 | 게임이 끝날 때 |

기존 라우터에 그대로 붙는다. `/play?id=`와 같은 방식이다.

## 3. `/start` — 첫 실행

**세 걸음. 그 이상은 안 된다.** 놀기 전에 넘어야 할 벽이 길면 그전에 그만둔다.

```
1  누가 놀 거예요?      [여자아이]  [남자아이]      ← 그림 두 장, 글자 없이
2  친구를 골라요!       [식물알] [공룡알] [토끼알]   ← 알 세 개, 흔들흔들
3  "함께 놀면 알이 깨져요!"  [시작하기]
```

- **이름은 안 묻는다.** 4~8세에게 키보드는 벽이다. 기본 이름을 주고,
  마이페이지(부모 화면)에서 부모가 고쳐준다. 목업의 연필 아이콘이 그 자리다.
- **나이도 안 묻는다.** 필요하면 부모 화면에서.
- 알은 **부화 전까지 바꿀 수 있다.** 첫 선택을 무겁게 만들지 않는다.
- 손 제스처로도 고를 수 있게 — 세 개짜리 큰 카드, 머무르기 1.2초.

---

## 4. `/buddy` — 내 친구 (아이 화면)

목업의 "나의 파트너" 카드를 **한 화면 전체로** 키운 것이다.

```
┌──────────────────────────────────────────┐
│  ← 뒤로                        ✋ 손 컨트롤 │
│                                          │
│              [ 버디 크게 ]                │
│                                          │
│            브레이브 렉스                  │
│         ⭐⭐⭐  LV.3                      │
│      ▓▓▓▓▓▓▓░░░░  조금만 더!             │
│                                          │
│   [ 🏅 내 배지 ]      [ 👕 꾸미기 ]       │
└──────────────────────────────────────────┘
```

- **버디가 화면의 주인공이다.** 가만히 있지 않고 숨 쉬듯 움직인다
- 레벨은 **별**로도 보여준다. 숫자를 못 읽어도 별은 센다
- 게이지 옆 문구는 숫자가 아니라 말 — "조금만 더!" · "거의 다 왔어!"
- 버튼 둘뿐. 세 개를 넘기지 않는다
- `👕 꾸미기`는 2차(형태 갈아입기·아이템)까지 **자리만** 둔다

### 배지 목록 (아이용)

큰 그리드. 못 딴 배지는 **회색 실루엣으로 보여준다** — "저건 어떻게 따지?"가 다음 동기다.
글자는 배지 이름만. 조건 설명은 부모 화면에.

## 5. `/me` — 마이페이지 (부모 화면)

**목업 구성을 거의 그대로 쓴다.** 다만 네 가지를 고친다.

### 고칠 것 1 — 점수를 앞세우지 않는다 ⚠️

목업 "최근 플레이"가 **최고 기록 2,450점**을 크게 보여준다.
이 서비스에서 점수는 부산물이고, 부모가 알아야 할 것은 **얼마나 움직였나**다.

```
✗  똥 피하기   최고 기록 1,820점
✓  똥 피하기   3번 · 12분 · 좌우 이동 48회
```

점수를 아예 지울 필요는 없지만 **작게, 아래에.**

### 고칠 것 2 — "오늘의 활동" 숫자가 위험하다 ⚠️

목업의 **활동 시간 2시간 40분**은 4~8세 기준으로 과하다.
(주간 그래프는 최대 28분인데 오늘만 2시간 40분 — 목업 안에서도 안 맞는다)

문제는 숫자 자체가 아니라 **천장 없이 누적을 자랑하는 형식**이다.
많이 할수록 잘한 것처럼 보이면, 부모가 더 시키고 아이는 지친다.
카메라를 켠 채 2시간이면 발열·배터리도 감당이 안 된다.

**목표 대비로 보여준다.**

```
오늘  ▓▓▓▓▓▓▓░░░  22분 / 30분
      "오늘 목표까지 8분!"
```

목표에 닿으면 축하하고 **거기서 멈춰도 된다고 말해준다.**
"더"가 아니라 "꾸준히"가 이 서비스가 파는 것이다.

### 고칠 것 3 — "연속"을 "이번 주에 n일"로

목업 배지 문구가 `연속 활동 6일` · `3일 연속 출석`이다.
`docs/05`에서 정한 대로 **기간 내 횟수**로 바꾼다. 아이가 아프거나 여행 가면
자기 잘못이 아닌 일로 기록이 사라진다.

```
✗ 3일 연속 출석
✓ 이번 주에 3일 놀기
```

### 고칠 것 4 — "피하기 30회" 배지는 운동이 아니다

`dodgeCount`는 가만히 서 있어도 오른다. `side_steps`(실제로 옮긴 횟수)로 바꾼다.
자세한 이유는 `docs/05` 4-1.

### 그대로 좋은 것

- **주간 성장 리포트 꺾은선** — 부모가 한눈에 읽는다. 이 화면의 핵심이다
- **오늘의 활동 5칸**(시간·점프·앉기·좌우·포즈) — 운동 종류가 보인다. 좋다
- **배지 최근 5개 + 더보기** — 구성 그대로
- 프로필 이름 옆 연필(수정) — 여기가 이름을 정하는 자리다

### 부모 화면은 손 제스처 대상이 아니다

`data-pz-hit`을 붙이지 않는다. 부모가 폰을 손에 들고 보는 화면이고,
작은 요소가 많아 손 커서로는 어차피 못 쓴다. **아이 화면만 손으로 된다**는 규칙을 지킨다.

> 허브 우상단 `👤 제라` 버튼이 이 화면으로 간다. **연결 완료 (8/9).**

## 6. 게임 결과 오버레이 — 보상이 도착하는 자리

**여기가 제일 중요하다.** 방금 몸을 움직인 직후라 감정이 열려 있다.
마이페이지에서 나중에 확인하는 것과는 무게가 다르다.

```
        게임 오버 / 클리어
        ────────────────
        ⭐ 새 배지!
        [배지 그림]  점프 챔피언

        LV.3  ▓▓▓▓▓▓▓░░  +40
        ────────────────
        [다시 하기]   [그만하기]
```

- **새로 딴 배지가 있으면 먼저 보여준다.** 점수보다 위에
- 레벨 게이지가 **차오르는 애니메이션** — 방금 한 운동이 눈에 보이게
- 부화·해금 같은 큰 사건은 **전용 연출**로 따로 (알이 깨지는 장면)
- 없으면 조용히 넘어간다. 매번 팡파레면 아무것도 특별하지 않다

## 7. 허브 홈에 버디 자리

기존 홈(히어로 + 한 줄 레일)을 크게 바꾸지 않는다. **버디를 한쪽에 작게 둔다.**

```
┌───────────────────────────────────────────┐
│ PLAY ZERA          ✋ 손 컨트롤  👤 제라  ☰ │
│                                           │
│   4-8세 · 순발력          [ 선택된 게임 ]  │
│   똥 피하기                                │
│   [▶ 시작하기]                             │
│                              ┌─────────┐  │
│                              │ 🥚 LV.3 │ ← 버디
│                              └─────────┘  │
├───────────────────────────────────────────┤
│  게임 20   ◀ [카드][카드][카드][카드] ▶    │
└───────────────────────────────────────────┘
```

- 누르면 `/buddy`로. 손 커서로 겨눌 수 있게 **카드와 가로로 떨어뜨린다**
- 레벨이 올랐거나 새 배지가 있으면 여기에 **빨간 점** — 아이가 보러 간다
- 좁은 화면에서는 버디를 숨긴다. 게임 고르기가 먼저다

## 8. 구현 순서

`docs/05` 8절의 개발 순서와 맞물린다.

| 순서 | 화면 | 선행 조건 |
|---|---|---|
| 1 | 게임 결과 오버레이에 배지·레벨 | `progress/` 뼈대 |
| 2 | `/start` 첫 실행 | 버디 registry |
| 3 | 허브 홈 버디 자리 | 위 둘 |
| 4 | `/buddy` 내 친구 | — |
| 5 | `/me` 마이페이지 | 주간 집계 쿼리 |
| 6 | 꾸미기(형태·아이템) | 2차 |

**게임 결과부터 만드는 이유** — 보상이 도착하는 자리가 먼저 있어야
나머지 화면이 "쌓인 걸 확인하는 곳"으로 의미가 생긴다.
반대로 하면 볼 게 없는 빈 화면부터 만들게 된다.
