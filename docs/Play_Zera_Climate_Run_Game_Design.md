# Play Zera — CLIMATE RUN 게임 기획안

> 버전: v0.1  
> 장르: Play Zera Runner / 1인칭 장애물 러너 + 환경 미션  
> 핵심 키워드: **달리기 · 장애물 회피 · 플로깅 · 분리배출 · 환경보호 · 보상**

---

## 1. 게임 한 줄 정의

**장애물을 피하며 달리고, 길에 버려진 쓰레기를 모은 뒤 올바르게 분리배출하여 환경을 깨끗하게 만드는 3스테이지 러너 게임.**

---

## 2. 기획 의도

CLIMATE RUN은 기존 Play Zera 러너 게임의 핵심 조작 방식을 유지하면서,  
아이들이 게임 안에서 자연스럽게 **“환경을 살리기 위한 행동”**을 경험하도록 설계한다.

게임의 중심은 교육 설명이 아니라 **행동 경험**이다.

- 달리면서 쓰레기를 줍는다.
- 환경오염과 기후 피해의 흔적을 장애물로 만난다.
- 스테이지 종료 후 모은 재활용품을 직접 분리배출한다.
- 마지막에는 일반쓰레기를 종량제 봉투에 담아 환경미화원에게 전달한다.
- 미션 수행 결과에 따라 **ZERA COIN**을 보상받는다.

### 핵심 메시지

> **“작은 행동이 지구를 더 깨끗하게 만들 수 있어.”**

# 4. 플레이 방식

기존 Play Zera 러너 게임의 기본 동작을 그대로 사용한다.

| 플레이 동작 | 게임 내 역할 |
|---|---|
| 좌우 이동 | 장애물 회피 / 쓰레기 수집 |
| 점프 | 낮은 장애물 또는 범람 물살 회피 |
| 스쿼트 / 앉기 | 낮게 걸린 장애물 통과 |
| 포즈 1 | 포즈 패널 통과 |
| 포즈 2 | 포즈 패널 통과 |
| 포즈 3 | 포즈 패널 통과 |
| 손 이동 | 분리배출 미션에서 쓰레기를 올바른 통으로 이동 |

### 포즈 미션

포즈 동작은 기존 Play Zera 러너에서 사용하던 방식 그대로 유지한다.

- 동작 자체는 변경하지 않는다.
- Climate Run에서는 **포즈 패널 디자인만 환경 테마에 맞게 변경**한다.
- 예: 나뭇잎, 지구, 물방울, 바람, 재활용 심벌 등을 활용한 디자인.

# 5. 핵심 차별화 시스템 — PLOGGING

CLIMATE RUN의 가장 중요한 차별점.

기존 러너에서 코인이나 아이템을 획득하듯,  
Climate Run에서는 **길에 떨어진 쓰레기를 주워 모은다.**

### 수집 방법

쓰레기가 배치된 레인으로 이동하면 자동 수집.

예:

- 페트병
- 플라스틱 컵
- 캔
- 금속 캔
- 종이
- 신문지
- 종이박스
- 유리병
- 비닐포장
- 과자봉지

### 기본 피드백 예시

- `CLEAN!`
- `+1`
- `RECYCLE!`
- `GOOD JOB!`

복잡한 텍스트보다 아이가 즉시 이해할 수 있는 시각/사운드 피드백을 우선한다.

# 6. 쓰레기 분류 체계

## 재활용 미션 메인 4종

1. **PLASTIC / 플라스틱**
2. **PAPER / 종이**
3. **CAN & METAL / 캔·금속**
4. **GLASS / 유리**

### 디자인 원칙

- 쓰레기통은 화면에 매우 크게 배치
- 위에서 안쪽이 보이도록 살짝 기울어진 원근
- 쓰레기통 안에는 예시 쓰레기를 소량만 배치
- 어린아이가 “어디에 넣는지” 즉시 알 수 있도록 시각적 힌트 제공
- 통 내부를 너무 꽉 채우지 않는다.

### 재활용 미션 조작

화면 중앙에 **쓰레기 1개만 크게 등장**한다.

아이의 손 움직임으로 해당 쓰레기를 알맞은 통으로 이동한다.

오른쪽 상단에는:

**NEXT TRASH**

형태로 다음 쓰레기를 작은 카드 UI로 미리 보여준다.

# 7. 일반쓰레기 처리 방식

일반쓰레기는 재활용품과 같은 방식으로 분류하지 않는다.

### 이유

- 일반쓰레기는 재활용 대상이 아니다.
- 어린아이에게 “모든 쓰레기가 재활용되는 것처럼” 보이는 것을 방지한다.
- 현실의 올바른 폐기 방식까지 경험하게 한다.

### 최종 처리

STAGE 3 완료 후:

**FINAL CLEAN-UP**

1. 러너 진행 중 모은 일반쓰레기 표시
2. 일반쓰레기를 종량제 봉투에 담기
3. 봉투를 정리
4. 환경미화원 캐릭터 등장
5. 아이가 봉투를 환경미화원에게 전달
6. 환경미화원이 밝게 인사 / 엄지척
7. 깨끗해진 환경을 보여주며 게임 종료

> 환경미화원은 단순 NPC가 아니라  
> **깨끗한 환경을 함께 만드는 사람**이라는 존중의 이미지로 표현한다.

### 목적
기후 피해가 본격적으로 등장하며 게임 난이도 상승.

### 난이도
**SPEED UP / 약 1.15x**

### 주요 장애물
- 회오리 / 강한 돌풍
- 쓰러진 나무

### 목적

### 난이도
**FINAL SPEED / 약 1.3x**

### 주요 장애물
- 강한 회오리
- 빠르게 좌→우로 흐르는 범람 물살
- 점프해야 하는 쓰러진 나무
- 좌우 회피용 큰 나무/낙석
- 낮게 부러진 나무
- 포즈 패널

### 연출
초반:
- 흐린 하늘
- 메마른 나무
- 탁한 물
- 환경 피해 흔적

진행할수록:
- 쓰레기가 줄어듦
- 물이 맑아짐
- 하늘이 밝아짐
- 나무와 꽃이 살아남

### 스테이지 종료
**RECYCLE MISSION 3**

분리배출 완료 후 최종 미션으로 연결.

# 9. 장애물 시스템

환경오염 및 기후위기의 결과를 **위험 장애물**로 표현한다.

## 좌우 회피

### 회오리 / 돌풍
- 한 레인을 막는 작은 회오리
- 먼지, 낙엽, 작은 잔해가 함께 회전
- 아이가 좌우 이동으로 회피

### 큰 돌 / 낙석
- 폭우 후 굴러온 돌
- 산사태 또는 기후 피해 연출

### 쓰러진 나무
- 한 레인을 막는 큰 나무
- 좌우 회피 장애물로 활용 가능

---

## 점프

### 낮은 쓰러진 나무
트랙 전체를 가로로 막고 있는 낮은 통나무.

### 범람 물살
트랙을 가로질러 **좌→우로 빠르게 흐르는 낮은 물살**.

- 너무 높은 파도 X
- 앞쪽으로 덮치는 파도 X
- 횡방향으로 지나가는 위험한 급류
- 아이가 점프로 통과

---

## 앉기 / 스쿼트

### 낮게 부러진 나무
- 트랙 위를 가로지르는 얇은 나무
- 스쿼트 자세로 충분히 통과 가능한 높이
- 나무 아래 공간이 명확하게 보여야 함

---

## 포즈 장애물

Climate Run에서는 **포즈 판의 시각 디자인만 환경 테마로 변경**.

# 10. 환경 피해 표현 원칙

게임은 특정 자연재해를 “길거리 쓰레기 때문에 바로 발생했다”고 단순화하지 않는다.

대신:

- 쓰레기 문제
- 환경오염
- 기후변화
- 폭우
- 강풍
- 범람
- 나무 피해
- 빙하 감소

등을 **“지구 환경이 아파지고 있다는 큰 맥락”**으로 표현한다.

### 핵심 표현

> **작은 행동이 모든 문제를 즉시 해결하지는 않지만,  
> 환경을 지키기 위한 행동은 우리 모두가 할 수 있다.**

---

# 11. 빙하 스테이지 확장 아이디어

초기 버전에서는 필수 아님.

추후 업데이트에서:

- 녹아내리는 빙하
- 떨어져 나온 얼음 조각
- 물 위를 떠다니는 빙하
- 녹는 북극 환경

등을 별도 테마 스테이지로 확장 가능.

# 14. 보상 시스템 — ZERA COIN

Climate Run 완료 시 **ZERA COIN**을 지급한다.

ZERA COIN은 Play Zera 전체 플랫폼에서 사용할 수 있는 공통 보상 화폐로 확장 가능하다.

### 보상 목적

환경 행동을 단순 교육으로 끝내지 않고  
**“미션 수행 → 성취 → 보상”** 게임 루프로 연결한다.

---

## 코인 획득 요소

| 행동 | 보상 예시 |

# 18. 어린이 UX 원칙

주 타깃이 어린아이이므로 다음을 우선한다.

1. 선택지는 최대한 크게
2. 동시에 보여주는 쓰레기는 1개
3. 색 + 아이콘 + 예시 오브젝트를 함께 사용
4. 실패 시 강한 패널티 금지
5. 정확한 행동을 칭찬하는 방식
6. 텍스트 설명 최소화
7. 동작 인식은 큰 실루엣 위주
8. 위험 쓰레기는 직접 수집 대상으로 사용하지 않음

### 직접 줍지 않는 품목

- 깨진 유리
- 날카로운 금속
- 배터리
- 화학물질
- 의료폐기물

아이에게 위험한 쓰레기를 직접 줍도록 학습시키지 않는다.

기존 Play Zera Runner:

**③ RECYCLE**  
스테이지 종료 후 분리배출

ZERA COIN + 환경 회복 연출
