## 핵심 원칙

- **폰이 본체, TV는 미러링된 모니터** — 기기 페어링 없음
- **조작 3층** — 게임 목록=손 포인터 / 확인·전환=O·X / 플레이=게임별 detector
- **운동 데이터 누적**이 플랫폼의 존재 이유
- **게임팩 구조** — `src/games/[id]/` 폴더 추가 = 자동 등록

## ⚠️ 건드리지 말 것

`src/core/pose/tuning.js`의 튜닝 상수는 현장 테스트로 다듬어진 값이다.
주석에 그 이유가 적혀 있다. **구조는 바꿔도 수치는 바꾸지 않는다.**

대표 사례:
- O만 머리 위 유지 요구, X는 미요구 (X 제한 시 플레이 중 인식률 급락)
- X는 어깨·손목만으로 판정 (전신 기준이면 달리기 중 발목 프레임 이탈)
- `GestureHold` 감소율 `dt × 0.6` (즉시 리셋 시 "잘 안 된다"는 체감)
