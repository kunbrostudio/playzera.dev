# 아이폰 Safari 검증 체크리스트

> 기준일 2026-08-03 · 대상 브랜치 `integrate-warmup`

v3에서 **"폰이 본체"**로 방향을 잡았다. 아이폰 사용자에게는 **모든 브라우저가 Safari(WebKit)** 다 — iOS의 크롬·파이어폭스도 내부 엔진은 WebKit이라 "크롬으로 우회"가 통하지 않는다. **Safari는 부차적 대상이 아니라 주 타깃이다.**

지금까지 검증은 전부 맥 크롬에서 했다. 이 문서는 그 사이 벌어진 간격을 메우기 위한 것이다.

---

## 0. 프리뷰 올리기

로컬 `npm run dev`로는 아이폰에서 카메라가 안 열린다. `getUserMedia`는 **보안 컨텍스트(HTTPS)** 를 요구하고, `localhost`는 그 기기 자신에게만 보안 컨텍스트다.

```bash
git add -A
git commit -m "STEP 4-6: 엔진 통일 · 손 포인터 · 카메라 공유"
git push -u origin integrate-warmup
```

Netlify 대시보드 → **Site settings → Build & deploy → Branch deploys** →
"Let me add individual branches"에서 `integrate-warmup` 추가.

배포되면 주소는 이 모양이다.

```
https://integrate-warmup--<사이트이름>.netlify.app
```

`main` 자동 배포는 그대로라 **운영본은 건드려지지 않는다.**

## 1. 먼저 확인할 것 — 여기서 막히면 나머지는 의미 없다

| 확인 | 통과 기준 | 실패하면 |
|---|---|---|
| 홈이 뜨는가 | 히어로 + 카드 한 줄 | 빌드·경로 문제 |
| **"✋ 손으로 고르기" 버튼이 보이는가** | 보임 | **iOS 16.4 미만이거나 WASM SIMD 미지원** — 콘솔에 `손 포인터 미지원` 이유가 찍힌다 |
| 버튼을 누르면 카메라 권한 팝업 | 뜬다 | HTTPS가 아니거나 Safari 설정에서 카메라 차단 |

> 버튼이 아예 안 보이면 그 기기는 **지원 하한선 아래**다. iOS 버전을 기록해두자. 이게 우리가 지원을 포기할 선을 정하는 근거가 된다.

## 2. 손 포인터

| 확인 | 비고 |
|---|---|
| 손을 어깨 위로 들면 커서가 나오는가 | |
| 커서가 심하게 떨리지 않는가 | 떨리면 `pointer.js`의 One Euro `minCutoff`·`beta` 조정 |
| 카드 위 1.2초로 선택되는가 | |
| 팔을 내리면 커서가 사라지는가 | |
| **다른 화면으로 갔다 돌아와도 다시 켜지는가** | iOS는 제스처 없이 `getUserMedia`를 거부한다 → **첫 탭 한 번**에 켜지도록 해뒀다. 아무 데나 한 번 눌러야 켜지면 정상 |

## 4. 화면

| 확인 | 비고 |
|---|---|
| 가로 모드에서 노치에 버튼이 가리지 않는가 | `env(safe-area-inset-*)` 적용함 |
| 하단 홈 인디케이터에 4칸 바가 깔리지 않는가 | |
| 주소창이 나타났다 사라져도 아래가 잘리지 않는가 | `100dvh` 폴백 적용함 |
| 게임 화면에서 스크롤 바운스가 없는가 | |

## 5. 성능·발열 — 실패해도 "안 되는 것"은 아니지만 기록해둘 것

| 항목 | 기준 |
|---|---|
| 콘솔에 `GPU delegate 실패 → CPU로 재시도` | 있으면 CPU로 도는 중 |
| 게임 중 체감 프레임 | 20fps 이상 |
| 20분 연속 플레이 시 발열 | |
| 미러링(AirPlay) 중에도 카메라가 유지되는가 | **티어 B의 전제인데 검증된 적이 없다** |

> 아이폰에서 콘솔을 보려면 맥의 Safari → 개발자 메뉴 → 기기 이름으로 연결한다.
> (아이폰 설정 → Safari → 고급 → 웹 속성(웹 인스펙터) 켜기)
